## BotFace API

<figure className="aligncenter size-large is-resized"><a href="/wp-content/uploads/2020/08/Tea-Cutie-Princess-The-Unstable.jpeg"><img src="/wp-content/uploads/2020/08/Tea-Cutie-Princess-The-Unstable.jpeg" alt="Tea Cutie Princess The Unstable is judging you" width="500" height="500" /></a><figcaption>Tea Cutie Princess The Unstable is judging you</figcaption></figure>

Last update I shared I had been working on BotFace, an API to generate bot faces! I had to do a lot of cleaning up, add some comments and also fix some performance issues with manipulating images in Javascript. 

But now I’m pleased to announce this sprint the API is now live and the source code can be found [here](https://github.com/SoSa-Community/FaceGenerator).

I’ll make an accompanying website shortly but for the minute the app is using these instead of the original icons we were using
