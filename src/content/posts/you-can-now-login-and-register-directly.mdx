Originally, Social Savanna was designed for the imgur only community. We quickly grew out of that and as we did almost every week someone would ask to be able to login to the site directly without needing Facebook / Twitter / etc.

This sounds like a basic thing these days but as a young startup I didn’t want to take the risk with security and passwords.

Now that we have moved servers and have a better understanding of the security protecting your passwords we’ve made it so you can both register and login using your own Social Savanna account.

Looking for new friends? [Signup today](https://chatplayshare.com/)

**Note:&#xA0;**&#x49;f you have an existing account and want a password. Just hit the “Forgot Password” button and create one, you’ll then be able to login with your newly created username and password ![:)](<./You Can Now Login And Register Directly - Social Savanna Behind The Scenes_files/simple-smile.png>)
