Ever since I began SoSa back in 2014, I wanted to find a way to make it open source!

Lack of time, resources and a bunch of clone sites popping up meant I didn’t ever get around to making the source code available on Github.

Well, that’s about to change!

With the relaunch of SoSa in 2020, it made sense to make at-least some of the code i’m working on Open Source!

This means you can re-use it (with attribution), suggest changes and a little later down the line collaborate with me on SoSa!

I’m still very cautious about people copying my work, a common trait amongst entrepreneurs so for the time being, only the front end’s, bot’s, apps and helper scripts that will be visible publicly.

Once SoSa has become more established again, i’ll open up a lot of the back-end code as well and hope to find ways we can collaborate on it’s future 🙂

If you want to keep an eye on what i’m doing, you can follow us on Github [here](https://github.com/SoSa-Community/)

\~James
